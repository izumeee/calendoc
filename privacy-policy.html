Calendoc プライバシーポリシー

最終更新日: 2026-07-25

Calendoc（以下「本アプリ」）は、イズミアプリケーション（個人開発者。以下「開発者」）が提供する iOS / macOS 向けカレンダーアプリです。 本アプリは「あなたの予定内容を開発者のサーバーへ送らない」ことを設計原則としています。

1. 予定・リマインダーのデータ

  • 本アプリは、お使いの端末のカレンダー・リマインダー（Apple の EventKit）を読み書きします。
  • これらのデータに対する本アプリの処理は端末内で行われ、開発者のサーバーに送信されることはありません（開発者はサーバーを運用していません）。
  • iCloud や Google などとの同期は、お使いの端末の OS またはお客様が接続した各サービスが行うものであり、それぞれの提供者のプライバシーポリシーが適用されます。

2. Google アカウント連携（任意機能）

Google カレンダーの拡張機能（勤務場所・イベントの色・出欠返信・Google Tasks）を利用する場合、本アプリは Google の OAuth 認証を通じてお客様の許可を取得します。

  • 本アプリは、接続したアカウントを識別・表示するため、Google のアカウント識別子、メールアドレス、表示名を取得します。
  • Google ユーザーデータ（予定・タスク・勤務場所等）の内容は、表示・編集のためにのみ使用し、広告・プロファイリング・第三者提供には使用しません。本アプリは、Google 連携機能が利用されたことを示す匿名の機能利用シグナルを送信する場合がありますが、Google ユーザーデータの内容、アカウント情報、認証情報は含みません。
  • Google ユーザーデータを、汎用的な AI または機械学習モデルの開発・改善・学習には使用しません。
  • 本アプリによる Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

3. Google ユーザーデータの保護

  • 本アプリと Google API 間のすべての通信は、HTTPS/TLS により転送中に暗号化されます。
  • Google のアカウント識別子、メールアドレス、表示名、および OAuth のアクセストークン・リフレッシュトークンは、お客様の端末にある Apple Keychain にのみ保存されます。Keychain は保存データを暗号化し、OS レベルのアクセス制御で保護します。
  • 本アプリは、Google API から取得する予定・タスク・勤務場所等の内容を保存するための永続データベースを作成・維持しません。これらの内容は、表示・編集に必要な一時的なアプリ状態として処理されます。
  • 本アプリは、お客様の端末から Google API に直接通信します。開発者が運営するバックエンドは Google ユーザーデータを受信せず、開発者がその内容へアクセスすることもありません。

4. Google ユーザーデータの保持と削除

  • Google API から取得した予定・タスク・勤務場所等の内容には長期の保持期間を設定していません。本アプリが管理する永続データベースには保存せず、現在の表示や操作に必要な一時的なアプリ状態は、データの再読み込み、アプリのプロセス終了、または不要になった時点で置き換えまたは破棄されます。開発者のサーバーには保持されません。
  • Google のアカウント情報と OAuth 認証トークンは、アカウントが本アプリに接続されている間だけ Keychain に保持されます。
  • お客様は本アプリの設定画面からいつでもアカウント連携を解除できます。解除処理では、そのアカウント情報と認証トークンを Keychain から削除し、以後本アプリはそのアカウントの Google ユーザーデータへアクセスしません。端末のストレージエラー等により削除について支援が必要な場合は、本ポリシー末尾の連絡先へお問い合わせください。
  • Google アカウント側の権限は https://myaccount.google.com/permissions からも取り消せます。
  • 開発者は Google ユーザーデータをサーバーに保存しないため、開発者側に保持されるサーバーデータはありません。削除について支援が必要な場合は、本ポリシー末尾の連絡先へお問い合わせください。

5. 利用統計（匿名・オプトアウト可能）

本アプリは、機能の改善のために TelemetryDeck を利用して匿名の利用統計（例: 画面の表示回数、機能の利用有無）を収集することがあります。

  • 予定・タスク・勤務場所の内容、Google アカウント情報、OAuth 認証情報が TelemetryDeck に送信されることはありません。
  • 収集される情報は匿名化されており、お客様個人を特定できません。トラッキング（アプリ・サイト横断の追跡）は行いません。
  • 設定画面の「匿名の利用統計を送信」からいつでもオフにできます。

6. 開発者が収集・利用しないもの

  • 予定、タスク、勤務場所、Google アカウント情報を開発者のサーバーへ収集しません。
  • 端末の連絡先や現在地にはアクセスしません。
  • 広告 SDK を含みません。
  • 予定、タスク、勤務場所、Google アカウント情報を販売、広告利用、または第三者提供しません。

7. お子様のプライバシー

本アプリは子どもを対象として設計されておらず、子どもから個人情報を故意に収集しません。

8. 変更について

本ポリシーを変更する場合、本ページを更新し、重要な変更はアプリ内でお知らせします。
