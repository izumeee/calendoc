Calendoc プライバシーポリシー

最終更新日: 2026-07-14

Calendoc（以下「本アプリ」）は、izumeee（個人開発者。以下「開発者」）が提供する iOS / macOS 向けカレンダーアプリです。 本アプリは「あなたの予定内容を開発者のサーバーへ送らない」ことを設計原則としています。

1. 予定・リマインダーのデータ

  • 本アプリは、お使いの端末のカレンダー・リマインダー（Apple の EventKit）を読み書きします。
  • これらのデータに対する本アプリの処理は端末内で行われ、開発者のサーバーに送信されることはありません（開発者はサーバーを運用していません）。
  • iCloud や Google などとの同期は、お使いの端末の OS またはお客様が接続した各サービスが行うものであり、それぞれの提供者のプライバシーポリシーが適用されます。

2. Google アカウント連携（任意機能）

Google カレンダーの拡張機能（勤務場所・イベントの色・出欠返信・Google Tasks）を利用する場合、本アプリは Google の OAuth 認証を通じてお客様の許可を取得します。

  • 本アプリは、接続したアカウントを識別・表示するため、Google のアカウント識別子、メールアドレス、表示名を取得します。
  • アカウント情報と認証トークンは端末の Keychain にのみ安全に保管され、開発者のサーバーには送信されません。
  • 本アプリは、お客様の端末から Google API に直接通信します。開発者が運営するサーバーや、その他の中継サーバーは経由しません。
  • 取得した情報（予定・タスク・勤務場所等）は表示・編集のためにのみ使用し、広告・分析・第三者提供には一切使用しません。
  • 連携はいつでも設定画面から解除でき、解除するとアカウント情報と認証トークンは端末から削除されます。Google アカウント側の権限は https://myaccount.google.com/permissions からも取り消せます。
  • 本アプリによる Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

3. 利用統計（匿名・オプトアウト可能）

本アプリは、機能の改善のために TelemetryDeck を利用して匿名の利用統計（例: 画面の表示回数、機能の利用有無）を収集することがあります。

  • 予定のタイトル・場所・参加者など、予定の内容そのものが送信されることは一切ありません。
  • 収集される情報は匿名化されており、お客様個人を特定できません。トラッキング（アプリ・サイト横断の追跡）は行いません。
  • 設定画面の「匿名の利用統計を送信」からいつでもオフにできます。

4. 開発者が収集・利用しないもの

  • 予定、タスク、勤務場所、Google アカウント情報を開発者のサーバーへ収集しません。
  • 端末の連絡先や現在地にはアクセスしません。
  • 広告 SDK を含みません。
  • 予定、タスク、勤務場所、Google アカウント情報を販売、広告利用、または第三者提供しません。

5. お子様のプライバシー

本アプリは子どもを対象として設計されておらず、子どもから個人情報を故意に収集しません。

6. 変更について

本ポリシーを変更する場合、本ページを更新し、重要な変更はアプリ内でお知らせします。
